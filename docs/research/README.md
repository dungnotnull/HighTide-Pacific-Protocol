# Research Bibliography

This folder contains the verified scientific bibliography for HighTide Protocol
(IEEE ClimateChain 2026). Every methodological choice and factual claim in the
project must be traceable to a reputable source listed in
[REFERENCES.md](REFERENCES.md).

## Contents

- `REFERENCES.md` — the curated, verified bibliography, organized by topic.
  Each entry has a stable citation ID (for example `[IPCC6-CH9]`) that is
  embedded in pipeline JSON outputs and shown in the UI.

## Citation policy

- Every entry was verified via web search at the time of writing (title,
  authors, venue/year, and a working link).
- We link to **official publisher pages and open-access versions** (IPCC,
  UN bodies, World Bank, NOAA/NASA, journal pages with DOIs, free textbooks).
  We never link to pirated PDFs or unauthorized copies.
- Peer-reviewed literature is preferred for scientific claims; official
  institutional documentation is used for datasets, standards, and policy
  instruments.
- To add a new reference: verify it exists (working URL, correct metadata),
  assign a stable ID, add a one-line relevance note and the "Supports" field,
  and update the Citation usage map at the bottom of REFERENCES.md.
